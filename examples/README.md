# NLTK Example Programs

This directory contains small example programs demonstrating common
features of the Natural Language Toolkit.

## Available Examples

- `tokenize_example.py` – tokenizes a simple sentence
- `pos_tag_example.py` – performs part-of-speech tagging
- `wordnet_synonyms_example.py` – retrieves synonyms from WordNet

Run an example with `python <scriptname.py>`.
